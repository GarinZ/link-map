# link-map 多选功能 PRD

## 1. 功能概述

允许用户同时选择树形结构中的多个标签页，进行批量操作（关闭、移动、分组、导出）。

## 2. 用户场景

- **批量清理**：关闭已完成研究的所有相关标签
- **整理**：将相关标签移动到新窗口或父节点
- **批量保存**：选中标签添加书签或复制链接列表

## 3. UI/UX 设计

### 3.1 复选框
- **位置**：图标左侧，始终可见
- **样式**：选中行高亮背景色（便于区分）
- **防误触**：复选框有足够 padding.2 父节点三态
- **Checked**：所有子节点选中
- **Un

### 3checked**：无子节点选中
- **Indeterminate**：1 到 (n-1) 个子节点选中

### 3.3 交互方式
| 操作 | 方式 |
|------|------|
| 单选 | 点击复选框 |
| 连续多选 | Shift + 点击 |
| 任意多选 | Ctrl/Cmd + 点击 |
| 全选 | Ctrl/Cmd + A |
| 取消 | Esc |
| 范围选择 | Shift + 方向键 |

### 3.4 批量操作栏
- 选中 n > 0 时显示
- 显示已选数量
- 显示可用操作

## 4. 功能需求

### 4.1 核心功能
- [ ] 始终可见的复选框 UI
- [ ] 单选/多选功能
- [ ] 父节点 indeterminate 状态
- [ ] 键盘导航支持
- [ ] 批量关闭
- [ ] 批量移动到新窗口
- [ ] 批量移动到指定位置
- [ ] 批量添加到分组
- [ ] 复制链接

### 4.2 状态管理
- 选中项在外部关闭时 **自动移除**
- 选择状态在展开/折叠时保持

### 4.3 快捷键
- `↑/↓`：焦点移动
- `Space`：切换选择
- `Shift + ↑/↓`：范围选择
- `Ctrl/Cmd + A`：全选
- `Esc`：取消选择
- `Enter`：执行主操作

## 5. 非功能需求

### 5.1 性能
- 100+ 节点选中 <100ms

### 5.2 无障碍 (Accessibility)
- `role="listbox"` 容器
- `role="option"` + `aria-selected` 项
- `aria-checked="mixed"` indeterminate 状态
- `aria-live="polite"` 已选数量播报

### 5.3 兼容性
- Chrome / Edge 兼容
- 暗色/亮色主题兼容
